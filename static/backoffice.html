Permanent table QR ordering — any Wi-Fi or mobile data

Generate each table code once from your LIVE Render back office. The link stays attached to that table even if its number changes. Do not print local-IP, localhost or temporary-host QR codes.

Permanent cross-network table QR codes are generated only by the publicly hosted HTTPS back office.

For PUBLIC HTTPS, scan the test QR with mobile data and then with a different Wi-Fi. For LOCAL access, scan on the same private Wi-Fi. Print table QRs only after the phone shows CONNECTED.

Every table QR offers Dine-In and Take-Out. Dine-In uses its assigned table; Take-Out is collected at the counter without a table assignment. Test the exact QR link on a phone before printing. Permanent table QRs point to a stable HTTPS table link; reusing the same printed code works across different networks and after table renaming. QR printing is only enabled from the public HTTPS back office.
